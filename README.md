# Домашнее задание 1: Реляционные базы данных (PostgreSQL)

## Как запустить:
1. Выполните команду для поднятия контейнера:
   ```bash
   docker compose up -d
   ```
2. Скрипты для создания таблиц и заполнения данными находятся в `init_db.sql`.
3. Запросы к БД `queries.sql`
4. Выполнить все запросы:
   ```bash
   .\run_queries.bat
   ```
